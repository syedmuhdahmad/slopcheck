# Governance

## Roles

- **Users**: anyone using slopcheck. Feedback, issues and examples are welcome.
- **Contributors**: anyone who has had a pull request merged.
- **Maintainers**: have write access, review and merge pull requests, triage issues, and cut releases. Listed in [`.github/CODEOWNERS`](.github/CODEOWNERS).

Current maintainer: [@syedmuhdahmad](https://github.com/syedmuhdahmad) (project lead).

## How decisions are made

- Day-to-day changes are decided through pull request review.
- Larger changes (new detectors, config format, breaking changes) are discussed in an issue or discussion first.
- We aim for consensus. If it can't be reached, the project lead makes the final call and explains why.

## Becoming a maintainer

Contributors who have made sustained, high-quality contributions (code, reviews or triage) may be invited to become maintainers by the existing maintainers.

## Changes to this document

Changes to governance go through a pull request and need approval from the project lead.
