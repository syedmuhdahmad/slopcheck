# Getting help

| You need… | Go to |
|---|---|
| Help using slopfence, or have a question | [Discussions → Q&A](https://github.com/syedmuhdahmad/slopfence/discussions) |
| To suggest an idea or give feedback | [Discussions → Ideas](https://github.com/syedmuhdahmad/slopfence/discussions) |
| To report a bug or false positive | [Open an issue](https://github.com/syedmuhdahmad/slopfence/issues/new/choose) |
| To report a security vulnerability | [SECURITY.md](SECURITY.md) (private, never a public issue) |

Please search existing issues and discussions before opening a new one.

slopfence is maintained by volunteers in their spare time. We'll do our best to respond, but there's no guaranteed response time for questions.
